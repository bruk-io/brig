## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
infra.placeholders.release handles each finished record on its own, in file order, and _remove drops a directory whose rmdir fails. When a crashed jail's record made W/.git and a later jail's record made W/.git/hooks inside it, a release that reads the dead record first fails rmdir(W/.git) (not empty), drops it, then removes W/.git/hooks: W/.git stays for good, a directory brig made and no record knows. Found by an embedder's killed-parent test, about half its runs.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 release removes every finished record's directories together, deepest first, so the order of records does not decide what is removed
- [ ] #2 A directory release could not remove for a reason other than being gone or replaced stays in a record, so a later release retries it
- [ ] #3 A test sweeps a dead record that made a directory before a live-then-finished one made directories inside it, in both file orders, and nothing brig made is left; recorded failing before the fix
