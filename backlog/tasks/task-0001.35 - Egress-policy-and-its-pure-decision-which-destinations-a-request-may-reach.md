## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
decision-0009 items 3 and 4, the pure half. A domain EgressPolicy(allow: tuple[Destination, ...]) with Destination(host, port): an exact hostname, *.suffix (names under the suffix, not the suffix), or an exact IPv4/IPv6 literal; the port always required, no CIDR, no port wildcards; refusals for a malformed entry. A pure decision: given the policy and a request (an authority from CONNECT, an absolute URL, or SOCKS5 with a name or a literal) and, for a name, its resolved addresses, allow or refuse with the reason; a resolved private, loopback, link-local, unique-local or metadata address is refused unless an IP-literal grant names it. Ported in spirit, not code, from the old brig's pure filter (old SPEC decisions 133/134).
<!-- SECTION:DESCRIPTION:END -->

**What was built.** `src/brig/domain/policy/egress.py`, beside `paths.py` and `env.py` (decision-0001's layout named `domain/egress.py`; the brief put it with the other policies, and the SPEC now says so):
- `Destination(host, port)`, `EgressPolicy(allow=())`.
- `egress_refusal(policy) -> DestinationRefusal | None`, one frozen refusal per malformed form, each carrying the entry: `EmptyHost`, `PortOutOfRange` (also a port that is not an `int`, such as `True`), `MisplacedWildcard`, `CidrNotation`, `InvalidHostname`, `NeedlessBrackets`. A valid hostname is ASCII labels of 1 to 63 characters, 253 at most, and a last label that inet_aton could not read as a number, so `127.1` and `0x7f000001` are refused, not looked up. A zoned IPv6 literal is `InvalidHostname`.
- `parse_authority(text, default_port=None) -> Authority | AuthorityUnparseable(text, AuthorityProblem)`. A SOCKS5 request builds `Authority(host, port)` directly, and `decide_egress` checks it again.
- `decide_egress(policy, request, resolved=None, host_addresses=()) -> Allowed | Resolve | NotGranted | Unresolved | AddressUnparseable | PrivateAddress | AuthorityUnparseable`.

**Three things beyond the brief, for the reviewer to judge:**
1. `Resolve(name)` is a third outcome. If one call took the resolved addresses as input, the proxy would have to resolve every name a jail asks for before deciding, and that would make the resolver a way out (`secret.attacker.example`). Now a name no grant matches is `NotGranted` and is never looked up. `Allowed.addresses` is what the proxy connects to, so nothing is resolved twice, and a name cannot rebind between the check and the connect.
2. `host_addresses`: decision-0009 item 4 names the jail's own host addresses. They arrive as data, and TASK-0001.36 has to supply them.
3. Public means `ipaddress` calls the address global and it is neither reserved nor multicast. That is wider than the listed ranges. It also refuses `100.64.0.0/10`, the documentation ranges, `fec0::/10`, 6to4 and Teredo. A NAT64 address (`64:ff9b::/96`) is judged by the IPv4 address it carries, so DNS64 networks keep working. An IPv4-mapped address is that IPv4 address everywhere: in matching, in exemptions and in `Allowed.addresses`.

**Presentation.** There are six errors in `errors.py`: `PolicyEgressHostEmpty`, `PolicyEgressPortOutOfRange`, `PolicyEgressWildcardMisplaced`, `PolicyEgressCidr`, `PolicyEgressHostInvalid` and `PolicyEgressNeedlessBrackets`. Each carries `.destination`. The translation is `check_egress_policy(policy) -> None` in `api.py`. It is public because a translation with no caller can be neither tested nor reached until TASK-0001.36, and because an embedder that builds a `Destination` from what its person typed needs to check it. If the owner would rather not have it, TASK-0001.36 can make it private when create calls it.

**Tests.**
- `tests/unit/test_egress_policy.py` (280 cases, Hypothesis strategies in `tests/unit/strategies.py`). They cover exact, suffix and literal matches, the suffix not matching itself or a lookalike, a port mismatch, case and a trailing dot, IPv6 brackets, and 35 private addresses, each refused without a grant, allowed with one, and still refused with a grant on another port. They also cover public and private addresses mixed at any position, the host's own address, malformed entries, 30 unparseable authorities, and never-raises properties over arbitrary text.
- `tests/integration/test_egress_policy_refusal.py` covers each error through the public API.
- A hand mutation run (dotless suffix match, dropped port filter, dropped exemption check, dropped NAT64 or mapped handling, dropped numeric-label rule, no `Resolve`, zones accepted) failed tests every time.

**Dev dependency.** `hypothesis==6.168.0`. 6.170.14's native module (`abi3t`) does not load on 3.15.0b4. 6.168.0 is what the old brig's workspace runs. brig itself still imports the standard library only.
