## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
decision-0009 items 1, 2 and 7. With an EgressPolicy, create_bwrap_jail starts a per-jail host-side proxy program (standard library only, importing nothing of brig, its own gate row) that speaks HTTP CONNECT, absolute-form HTTP and SOCKS5 CONNECT and decides with the pure function; the supervisor listens on 127.0.0.1:<port> in the jail's network namespace and, per accepted connection, sends one end of a socketpair to the proxy over an fd it inherited (SCM_RIGHTS) and relays the other; brig sets HTTP_PROXY, HTTPS_PROXY, ALL_PROXY=socks5h://... (and lower-case) and NO_PROXY/no_proxy empty, refusing an EnvPolicy that names them; destroy_jail ends the proxy (law 7).
