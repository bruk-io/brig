## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
decision-0009 items 1, 2 and 7. With an EgressPolicy, create_bwrap_jail starts a per-jail host-side proxy program (standard library only, importing nothing of brig, its own gate row) that speaks HTTP CONNECT, absolute-form HTTP and SOCKS5 CONNECT and decides with the pure function; the supervisor listens on 127.0.0.1:<port> in the jail's network namespace and, per accepted connection, sends one end of a socketpair to the proxy over an fd it inherited (SCM_RIGHTS) and relays the other; brig sets HTTP_PROXY, HTTPS_PROXY, ALL_PROXY=socks5h://... (and lower-case) and NO_PROXY/no_proxy empty, refusing an EnvPolicy that names them; destroy_jail ends the proxy (law 7).

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
### Design
Approach: the jail keeps `--unshare-all` (its own network namespace, loopback only). With an `EgressPolicy`, the supervisor listens on 127.0.0.1:3128 inside the jail and relays each connection over a socketpair whose other end it hands, with SCM_RIGHTS, to a per-jail proxy process on the host. The proxy decides with `domain/policy/egress.py`'s `decide_egress`, which reaches it as source, never as an import. With no policy, nothing new runs and nothing changes.

**How the decision reaches the proxy without importing brig.** `infra/proxy/assemble.py` builds the proxy file the way `infra/supervisor/assemble.py` builds the supervisor's. It has the same 2.7-parseable version guard (shared through a public `guard(name)` in the supervisor's assemble), then two base64 blobs:
1. `egress.py`'s source, exec'd into a fresh module `brig_egress_decision`, registered in `sys.modules` so its dataclasses resolve;
2. `infra/proxy/program.py`'s source, exec'd as `__main__`. Its guard calls `_main(sys.modules[DECISION_MODULE])`.

`program.py` takes the decision module as a value (a `ModuleType`) and converts what it answers into its own values at one seam (`_judge`), so mypy checks everything past it. infra cannot import domain, so the assembler takes the decision source as data: presentation reads `Path(egress.__file__)` and passes the text. A new gate rule, `brig-standalone-programs`, lists the modules shipped as source: the proxy program, `egress.py`, the supervisor's `program.py` and `wire.py`. None of them may import anything of `brig`. A planted-violation test lands with the rule. The decision's other pure rule (`brig-pure-domain`) already keeps `egress.py` free of I/O.

**Where the proxy runs.** It runs on the host, as a child of the embedder. It is started by the supervisor link (`infra/proxy/launch.py`, called from `link._start`) before the supervisor, and it lives as long as the jail:
- **How it starts:** `sys.executable -I -` with its source written to its stdin, so no file is written anywhere and nothing in the jail's view (nor the state directory) names it.
- **Its fds:**
  - 0: the source;
  - 1 and 2: `/dev/null` (rule 14: no stray lines; the JSON decision log is TASK-0001.37's);
  - 3: the config pipe, one JSON line `{allow, hosts}`, with the write end held by the link for the jail's life so TASK-0001.37 can send changes;
  - 4: its end of a SOCK_SEQPACKET socketpair whose other end becomes the supervisor's fd 5.
- **Its environment:** fixed, `PATH` only.
- **When it exits:** on end of file on fd 3 or fd 4.
- **How it ends:**
  - **Normally:** `Supervisor.close` (reached by `await_done`'s terminal outcome and by `dismantle` through `SupervisorPort.close`, so `destroy_jail` and a failed create both get it) closes the config pipe, polls for up to 1 s, then KILLs the proxy's own group and reaps it. A reaped pid is the verification.
  - **When the start fails part way:** the proxy is the link's own child, not the jail's group, so `_start` ends it itself on every failure path after its spawn.

**The bridge in the supervisor.**
- **The request:** the exec request gains `bridge_port` (`wire.py`, closed TypedDict, `None` without egress), and `wire.BRIDGE_FD = 5`.
- **Before the command starts:** with a port, `program.py` binds 127.0.0.1 (and `::1`, IPV6_V6ONLY, when the namespace has it) and sets fd 5 non-inheritable, so the port is held before any program could take it.
- **After the start:** a daemon thread accepts. For each connection it makes a socketpair, sends one end to fd 5 with `socket.send_fds` and closes its copy, then relays the accepted connection and the kept end on two threads, copying bytes only.

**Why this does not widen what the command can reach.**
- **What the command inherits:** nothing new. The listeners and socketpairs are CLOEXEC, and fd 5 is non-inheritable (with a CLOSE file action, like 3 and 4).
- **The supervisor's fds:** `/proc/1/fd/5` stays refused because PID 1 is non-dumpable and the jail holds no capabilities (decision-0006).
- **What PID 1 parses:** nothing the command sends. The only new reach is a TCP port on the jail's loopback whose far end is the proxy, which decides.

**The environment.**
- **The variables:** `domain/policy/env.py` gains `PROXY_VARIABLES` (HTTP_PROXY, HTTPS_PROXY, ALL_PROXY, NO_PROXY and their lower-case forms), `proxy_environment(port)` (`http://127.0.0.1:<port>` for the HTTP pair, `socks5h://127.0.0.1:<port>` for ALL_PROXY, empty NO_PROXY/no_proxy), and `proxy_variable_refusal(policy)`.
- **How they reach the command:** `Plan` gains `set_env`, which `operations.create` lays over the scrubbed environment. `bwrap.compile_run(command, env, egress_port)` fills it, and `bwrap.EGRESS_BRIDGE_PORT = 3128`.
- **The refusal:** an `EnvPolicy` naming one of these with an `EgressPolicy` raises `PolicyEnvNamesProxyVariable`. Without one, behaviour is unchanged.

**Policy check.** `create_bwrap_jail(..., egress: EgressPolicy | None = None, egress_hosts: Mapping[str, tuple[str, ...]] | None = None)` refuses a bad policy first, through one translation `api.check_egress_policy` shares (moved to `presentation/jail.py`), before anything is written. This makes that docstring true.

**The proxy.**
- **Protocols:** it sniffs the first byte. 0x05 is SOCKS5 (no-auth CONNECT only; atyp 1, 3 and 4; any other command gets 0x07). Anything else is HTTP: `CONNECT host:port` (authority via `parse_authority`) and absolute-form `http://` with the request line rewritten to origin-form, Proxy-* headers dropped and `Connection: close` set, so one request goes to one decided destination.
- **The decision:** `decide_egress` with no addresses first. On `Resolve` the proxy resolves the name itself and asks again with the addresses and its host's own addresses, read from `/proc/net/fib_trie` (LOCAL /32) and `/proc/net/if_inet6`. It connects only to `Allowed.addresses`, in order, and never looks up a name again.
- **Answers:**
  - a refusal: `403` with the body `brig: egress denied by policy: host:port`, or SOCKS reply 0x02;
  - `Unresolved`: `502`, or SOCKS 0x04;
  - a connect failure: `502`, or SOCKS 0x05;
  - an unreadable request: `400`, or SOCKS 0x01.
- **The resolver seam:** `egress_hosts`, plain data, is a table the proxy resolves from instead of `getaddrinfo`. A name absent from it resolves to nothing.

### Risks
- bwrap passing fd 5 through, measured only for 3 and 4. To check first.
- Threads in PID 1: the command is spawned before any thread starts, and signals stay on the main thread, which reaps.
- A proxy that died: `send_fds` fails, and the supervisor closes the connection, failing closed.
- Leaks on the start's failure paths: each path ends the proxy and closes its fds. The integration and e2e tests count fds.
- Blocking stdin write of about 50 KB of source: python reads at once. If its exec fails, EPIPE becomes `SupervisorSpawnError`.
- Host addresses from /proc on Linux only (bwrap is Linux only).
- Port 3128 is fixed per jail, inside the jail's own namespace.
- The size: if the bridge or the proxy grows past this plan, stop and split: the proxy and its gate as one change, the bridge and wiring as the next.

### Proof

- `granted.test:<port>` plus an IP-literal grant `127.0.0.1:<port>` is reached over CONNECT and over SOCKS5 (socks5h), and through urllib reading `HTTP_PROXY` (absolute-form). The literal is needed because item 4 refuses a name that resolves into loopback without one, which the next point also proves.
- `local.test`, granted by name only and mapped to 127.0.0.1, is refused with the 403 signature and with SOCKS 0x02.
- An ungranted name gets the 403 body and SOCKS 0x02.
- A program that ignores the settings and dials the server's address directly reaches nothing.
- Nothing in the jail names the proxy: the environment holds only 127.0.0.1, and the jail's /proc shows no proxy process.
- After `destroy_jail`: the proxy's pid is reaped (`waitid` ECHILD), the embedder's thread count is back to its baseline, and its fd set is back to its baseline.
