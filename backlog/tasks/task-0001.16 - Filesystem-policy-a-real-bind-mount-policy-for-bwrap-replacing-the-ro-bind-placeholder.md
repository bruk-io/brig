## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
### Order of work
1. domain/policy/paths.py: FsPolicy(binds), Bind(host_path, jail_path, writable). Pure data.
2. jail_types/bwrap.py's compile_run takes a policy param, translates binds into --ro-bind/
   --bind flags ahead of the existing --unshare-all/--die-with-parent/--new-session, replacing
   the current --ro-bind / / placeholder (keep that as the *default* policy for now -- a real
   per-embedder policy API is out of scope here, just the mechanism).
3. presentation/api.py threads a policy parameter through to compile_run.
4. e2e battery: a path outside the policy is unreadable/unwritable in a real bwrap jail
   (skip-guarded on this host), with a positive control (the same path IS reachable with no
   policy, i.e. today's placeholder behavior), per rule 11.

### Risks
- Changing the default policy away from whole-host-read-only could silently break the existing
  walking-skeleton e2e test if it is not also updated to pass an explicit (or default) policy.

### Proof
- just gates, just typecheck, just done green; the new battery's positive control genuinely
  shows the violation when planted.
