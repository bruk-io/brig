## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Found in TASK-0001.25's review. domain/channels.py's reserve() derives a reservation's endpoint by joining the channel directory and the name, but never checks the result against the AF_UNIX sun_path limit (about 108 bytes on Linux, 104 on macOS). A long BRIG_HOME (or a long channel name) yields an endpoint that bind() and connect() will refuse, and nothing says so until the jailed program fails to listen.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 reserve refuses, as a value (not raised), an endpoint longer than the platform's AF_UNIX path limit; a unit test pins it
- [ ] #2 reserve refuses an endpoint whose encoded byte length is over the AF_UNIX sun_path limit (108 on Linux, NUL included; the limit is a domain constant or parameter, since the domain may not import socket); repro test: reserve((Channel('s'),), ChannelDirectory('/'+'a'*120, '/'+'a'*120)) returns Reservations today
- [ ] #3 reserve_channels raises a typed error naming the path and saying to shorten BRIG_HOME or the channel name
- [ ] #4 A unit test pins both sides of the limit
<!-- AC:END -->

- AC#1/#2: `domain/channels.py` gains `SUN_PATH_BYTES_LINUX = 108` and `SUN_PATH_BYTES_DARWIN = 104` (sun_path's size, NUL included; domain constants since the domain may not import socket) and `ChannelEndpointRefusal(name, endpoint, length, limit)`. `reserve` takes keyword `sun_path_bytes` (Linux's by default) and refuses, as a value, the first endpoint whose UTF-8 (surrogateescape) bytes are `>= sun_path_bytes`. Name refusals come first. Only the endpoint (the jail-side path the jailed program binds) is measured: the host connects through `/proc/self/fd/N`, never by `bound_path`, so a long host path alone is not refused.
- AC#3: `reserve_channels` passes this platform's size (macOS's on `sys.platform == "darwin"`, Linux's otherwise) and raises the new `ChannelEndpointTooLong(name, endpoint, length, limit)`, whose message names the endpoint and its length and says to shorten BRIG_HOME or the channel name, and by how many bytes. Nothing is created first (`allocate` creates nothing). tests/integration/test_channel_endpoint_too_long.py pins it, with a short-directory control.
- AC#4: tests/unit/test_channels_path_limit.py pins 107 bytes reserved and 108 refused, bytes not characters, the host path not measured, the macOS limit, and a bad name still refused first.
- Public API: `brig.ChannelEndpointTooLong` added; `reserve_channels` documents it under Raises. SPEC (docs/spec/index.md, domain section) updated with the refusal.
