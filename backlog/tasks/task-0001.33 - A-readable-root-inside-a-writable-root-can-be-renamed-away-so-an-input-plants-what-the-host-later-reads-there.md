## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
TASK-0001.31 pins the directories between a writable root and a write deny or mask. A readable root nested in a writable root has the same hole: measured with readable / and W/z/r, writable W, the jail renamed W/z, created W/z/r/tool, and the host then read the planted file. An embedder that keeps its own code read-only inside a writable project relies on this. Found by TASK-0001.31's worker.
<!-- SECTION:DESCRIPTION:END -->
