## Why

TASK-0001.05's AC#2 asks that bwrap's `--new-session` flag close the TIOCSTI escape "and not infra's setsid". As built, `brig.infra.processes.spawn` sets `setsid=True` unconditionally, inside `os.posix_spawnp`, before bwrap's own argv is ever parsed by the sandboxed process. That means the spawned process's session is already detached -- and the TIOCSTI hole already closed -- before `--new-session` could do anything of its own. Measured directly while fixing review findings on TASK-0001.05: a child started through `brig.infra.processes.spawn` with no bwrap involved at all already cannot inject via TIOCSTI (EACCES on this host's kernel, EPERM on Linux).

`tests/e2e/test_tiocsti_battery.py` therefore grades the end-to-end property (TIOCSTI stays denied, through the gateway and through a real bwrap jail) but cannot, as a black-box battery, attribute that denial to bwrap's own flag over infra's plumbing -- both close the same hole, and the weaker of the two (infra's) already suffices alone. `domain/jail_types/bwrap.py`'s own docstring explains why `--new-session` is kept anyway (defense in depth: it keeps the property true if infra's spawn ever stops setting `setsid=True` for an unrelated reason), but that is not the same as a battery that would notice a regression specifically in the jail type's own policy.

## What this task is

Design and build a way to grade that attribution for real -- for example, a battery that can run the probe through a path where infra's own session-detaching is held constant and only the jail type's flag varies (or an equivalent that does not require weakening infra's own spawn safety to prove it). This is a battery/architecture problem, not a one-line fix: it may need a seam in how a jail type's own flags are asserted independently of infra's behavior, consistent with decision-0001 rule 11 (grades come only from evidence) and rule 3 (a jail type's slice stays self-contained).

Out of scope for this task: changing infra's own `setsid=True` behavior, which TASK-0001.06 already settled for unrelated reasons.
