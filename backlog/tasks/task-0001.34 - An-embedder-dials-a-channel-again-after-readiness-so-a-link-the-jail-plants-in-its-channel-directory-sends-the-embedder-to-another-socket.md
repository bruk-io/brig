## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
await_channel_ready makes a verified connect (decision-0005: the peer listens inside the jail's PID namespace), then closes it and returns ChannelReady carrying nothing. The embedder then dials the reservation's host path itself with a plain connect, which follows a symlink. The jail can write its channel directory, so once readiness has passed it can replace its socket with a link to any socket the embedder's user can reach on the host (an agent socket, a container daemon), and the embedder connects there and speaks its protocol to it. The old brig refused a link in the channel directory on every connect. Found by an embedder's review of its channel owners.
<!-- SECTION:DESCRIPTION:END -->
